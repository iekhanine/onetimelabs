# Readability + Contact Center Update

## Contact center experience
- Corrected migration direction to Five9 → Genesys.
- Enterprise landing page now describes transition management across ACD queue/agent routing, assignments, transfers/escalations, IVR/IVA call flows, call recording/ACR, validation, and production troubleshooting.
- Enterprise Experience page now explicitly identifies the Google / Nest context and uses the same technical scope.

## Typography
- Company-site font declarations below 12px were raised to a 12px minimum.
- Core service descriptions, page-hero body copy, contact copy, and compact service descriptions were raised to 13–14px.
- Layout dimensions and headline scale remain compact; this is a readability pass, not a return to oversized marketing sections.
